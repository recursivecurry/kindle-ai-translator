KINDLE AI TRANSLATOR

kindle-ai-translator

선택한 원본 언어의 본문을 기기에서 인식하고, 선택한 언어의 번역을 책 위에 표시합니다.

기본 5개, 최대 30개입니다. 두 쪽이 한 이미지인 화면은 1개로 셉니다. 캐시는 최대 24MB·10분이며 한도를 먼저 넘으면 오래 사용하지 않은 항목부터 지웁니다. 이전 페이지 보기에서는 현재·이전 화면에 필요한 이미지를 한도보다 우선 보관합니다.

선택한 글꼴에 없는 문자는 시스템의 대체 글꼴로 표시합니다.

100%는 원문 글자 높이에 맞춘 크기입니다. 70~130%로 조절할 수 있습니다. 문단 안에서 줄바꿈하며, 공간이 부족하면 설정 크기의 85%까지 줄입니다. 그래도 맞지 않으면 원문을 유지합니다. 설정 저장 시 현재 페이지를 다시 번역합니다.

현재 화면의 OCR 텍스트와 직전에 번역한 페이지의 원문·번역문을 OpenAI에 전송합니다. 책 이미지와 API 키는 킨들 페이지에 전달하지 않습니다. API 사용료는 OpenAI 계정에 별도로 청구됩니다.

번역 모델: gpt-6-luna. 키는 이 브라우저의 확장 저장소에 보관하며 동기화하지 않습니다. 이 기기를 사용하는 다른 사람이나 개발자 도구로는 접근할 수 있습니다.

확장을 처음 설치했다면 킨들 탭을 새로고침하세요. 본문 옆 도구에서 원문 보기와 다시 시도를 사용할 수 있습니다. Alt+Shift+T로 원문과 번역을 전환합니다. Mac에서는 Option+Shift+T입니다. 입력란에서는 단축키가 작동하지 않습니다.

번역문은 드래그해서 선택하고 복사할 수 있습니다. 원문의 쪽 배치와 문단 위치를 유지하며, 공간이 부족한 문단은 원문으로 남깁니다.

사진 위의 글, 표와 수식은 지원을 보장하지 않습니다. 배경이나 배치가 안전하지 않은 문단은 원문으로 남기고 알려 드립니다.
