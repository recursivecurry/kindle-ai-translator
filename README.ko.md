# kindle-ai-translator

[English](README.md)

킨들 웹 리더의 책을 번역하면서 원래 페이지 배치를 최대한 유지하는 Chrome 확장입니다. 번역문을 드래그해서 선택하고 복사할 수 있습니다.

## 실험용 프로젝트 및 이용 책임

이 확장은 개인적인 실험의 결과물입니다. Amazon, 출판사 또는 저작권자와 제휴 관계가 없으며, 이들의 승인이나 후원을 받은 제품이 아닙니다.

접근 및 처리가 허용된 콘텐츠에 한해 관련 저작권법과 [Kindle Store 이용약관](https://www.amazon.com/gp/help/customer/display.html?nodeId=201014950)을 준수하여 사용하세요. 책을 구매했거나 열람할 수 있다는 사실만으로 모든 형태의 복제, 번역, 외부 API 전송 또는 재배포가 허용되는 것은 아닙니다. DRM 등 접근 통제를 우회하거나, 권리자의 허락 또는 법적 근거 없이 원문·번역문을 복제·공유·공개하는 용도로 사용하지 마세요.

이용이 허용되는지 확인하고 자신의 이용 행위에 책임을 지는 것은 사용자입니다. 이 확장은 관련 법률이 허용하는 범위에서 어떠한 보증 없이 있는 그대로 제공됩니다. 이 안내는 책에 대한 이용 권한을 부여하거나, 법률상 배제할 수 없는 책임을 면제하지 않습니다.

이 확장은 화면에 표시된 페이지 이미지를 읽고, 단어 좌표를 얻기 위해 Kindle 내부 렌더러를 사용합니다. 로컬 처리나 이 안내만으로 특정 이용이 Amazon 약관에 부합한다고 판단할 수는 없습니다. 소프트웨어 관련 조항을 포함한 [Amazon 이용약관](https://www.amazon.com/gp/help/customer/display.html?nodeId=GLSBYFE9MGKKQXXM)과 이용 지역·도서에 적용되는 조건을 확인하세요. 이 프로젝트는 이용의 적법성이나 계정 제한으로부터의 보호를 보장하지 않습니다.

권리 침해가 우려되는 부분은 해당 파일 또는 URL과 문제의 근거를 적어 [GitHub 이슈](https://github.com/recursivecurry/kindle-ai-translator/issues)로 알려 주세요. 이슈는 공개되므로 책 본문, API 키, 비공개 계정 정보를 첨부하지 마세요.

## 동작 예제

루이스 캐럴의 《이상한 나라의 앨리스》에서 같은 페이지의 영어 원문과 한국어 번역을 비교한 화면입니다. 좌우 두 쪽 배치를 유지하며, 영어 원작의 저작권 보호기간은 만료되었습니다.

스크린샷은 Kindle 판본과 이 확장이 생성한 번역을 보여 주며, 출판된 한국어 번역본을 사용하지 않았습니다. [Project Gutenberg의 작품 정보](https://www.gutenberg.org/ebooks/11)는 원작이 미국에서 퍼블릭 도메인이라는 근거로 참고할 수 있으며, 이 스크린샷의 출처는 아닙니다. 현대 번역본·추가 삽화·Kindle 인터페이스에는 별도 권리가 있을 수 있습니다. 이 예시는 모든 판본이나 이용 방식에 제한이 없다는 뜻이 아닙니다.

## 설치

Chrome 116 이상과 설치용 확장 ZIP 파일이 필요합니다. OpenAI 번역에는 API 키가 필요하며, Chrome 로컬 번역을 선택하려면 데스크톱 Chrome 138 이상과 지원하는 기기·언어 조합이 필요합니다. 저장소의 **Download ZIP**은 소스 코드이며 바로 설치할 수 있는 확장 파일이 아닙니다.

1. 설치용 ZIP을 컴퓨터에 계속 보관할 폴더에 압축 해제합니다.
2. `chrome://extensions`에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다. `manifest.json`이 있는 폴더를 지정합니다.
3. 확장 아이콘을 눌러 OpenAI API(기본값) 또는 Chrome 로컬 번역과 원본·번역 언어를 선택합니다. 자동 번역을 켜고 저장합니다. OpenAI를 사용하려면 API 키를 입력하세요. 로컬 번역은 저장할 때 Chrome 모델을 준비하며, 필요한 경우 다운로드 진행 상태를 표시합니다.
4. 열려 있던 킨들 탭을 새로고침하고 책을 엽니다.

지원 주소: `read.amazon.com`, `read.amazon.co.uk`, `read.amazon.co.jp`, `read.amazon.de`.

## 읽기와 번역

뷰어 오른쪽 아래 메뉴에서 다음 기능을 사용할 수 있습니다.

- 원문과 번역문 전환
- 번역 재시도, 번역 끄기·켜기
- 원본 언어와 번역 언어 변경
- **이전 페이지 보기** 켜기·끄기

**Alt+Shift+T**로 원문과 번역문을 전환합니다. Mac에서는 **Option+Shift+T**입니다. 번역문은 드래그해서 선택하고, 페이지는 킨들의 화살표나 여백을 눌러 넘깁니다.

### 이전 페이지 보기

책에서 바로 앞에 있는 페이지를 보여 주면서 현재 킨들 페이지를 백그라운드에서 번역합니다. 예를 들어 킨들이 3페이지로 이동하면 2페이지를 읽게 됩니다. 다시 2페이지로 돌아가면 캐시에 있는 1페이지를 보여 줍니다.

페이지를 넘길 때는 다음 표시가 준비될 때까지 기존 화면을 유지합니다. 번역문보다 캐시된 원문이 먼저 표시될 수 있습니다. 앞 페이지를 확인할 수 없거나 캐시가 없으면 현재 페이지를 표시합니다.

킨들의 Location과 진행률은 여전히 현재 페이지 기준입니다. 원문·번역 전환은 실제로 보고 있는 페이지에 적용됩니다. 확장이 자동으로 페이지를 넘기거나 아직 방문하지 않은 페이지를 미리 번역하지는 않습니다.

## 설정

확장 아이콘을 눌러 설정을 엽니다. 설정은 모든 킨들 탭에 적용됩니다.

| 항목           | 선택 범위                                                                                                               |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 번역 엔진      | OpenAI API(기본값) 또는 Chrome 로컬 Translator API. 엔진을 바꿔도 저장된 API 키는 유지하며, 이전 엔진의 번역 결과는 새 엔진에서 재사용하지 않습니다. |
| 원본·번역 언어 | 영어, 한국어, 일본어, 중국어 간체·번체, 스페인어, 프랑스어, 독일어, 포르투갈어, 베트남어. 기본값은 영어 → 한국어입니다. |
| 글꼴           | 나눔고딕 또는 나눔명조. 글꼴에 없는 문자는 시스템 대체 글꼴로 표시합니다.                                               |
| 글자 크기      | 추정한 원문 크기의 70~130%                                                                                              |
| 캐시 크기      | 페이지 이미지 1~30개, 기본 5개. 두 쪽이 한 이미지인 화면은 1개로 셉니다.                                                |

페이지 이미지·OCR 결과·번역문은 메모리에 캐시하며, 확장이 책 파일로 저장하거나 동기화하지 않습니다. 이미지 캐시는 24MB를 기준으로 관리하고, 조회 시 10분의 만료 기준을 확인합니다. 이전 페이지 보기에 필요한 이미지는 보호되는 동안 제거 대상에서 제외됩니다. 모든 데이터가 10분 후 삭제된다는 뜻은 아닙니다. 킨들 탭을 닫으면 해당 뷰어의 캐시가 사라집니다. 메모리 제한으로 설정한 수보다 적게 남을 수 있습니다.

## 개인정보와 비용

문자 인식은 기기에서 실행합니다. OpenAI를 선택하면 인식한 본문과 관련된 앞 페이지의 원문·번역문을 OpenAI에 전송하며, 책 이미지는 보내지 않습니다. Chrome 로컬 번역을 선택하면 기존 OCR·합성 흐름 안에서 본문을 기기에서 번역합니다. Chrome이 번역 모델을 다운로드할 수 있지만, 로컬 모드에서 OpenAI를 호출하거나 자동으로 전환하지 않습니다.

API 키는 이 브라우저의 확장 저장소에 보관하며 동기화하지 않습니다. 기기에 접근할 수 있는 사람은 키에도 접근할 수 있습니다. OpenAI API 사용료는 ChatGPT 구독과 별도이며, 새 번역과 재시도에는 비용이 발생할 수 있습니다. Chrome 로컬 번역에는 키와 API 사용료가 필요하지 않습니다. 두 모드 모두 기존 임시 페이지 캐시와 이전 페이지 보기를 유지합니다.

새로 설치하면 자동 번역은 꺼져 있습니다. 자동 번역을 켜면 이후에 여는 페이지를 포함해 모든 킨들 탭에 선택한 엔진이 적용됩니다. OpenAI를 선택하면 API 키는 OpenAI로 직접 보내는 요청의 인증에 사용하며 킨들 페이지에는 전달하지 않습니다. 외부 처리가 허용되는 콘텐츠인지 확인한 뒤 켜세요. 뷰어나 설정에서 번역을 끄면 자동 번역을 중단할 수 있습니다. 로컬 엔진은 외부 전송을 줄이지만 콘텐츠의 번역·복제 권한을 부여하지는 않습니다.

OpenAI 요청에는 응답 저장을 끄는 `store: false`를 사용합니다. 이는 보관이 전혀 없다는 뜻이 아닙니다. 악용 방지 로그에 입력·출력이 포함되어 기본적으로 최대 30일 보관될 수 있으며, 법률상 의무나 안전상 필요 등에 따른 예외가 있습니다. 계정별 설정에 따라 정책이 달라질 수 있으므로 [OpenAI 데이터 관리 안내](https://developers.openai.com/api/docs/guides/your-data)를 확인하세요. 이 확장에는 개발자가 운영하는 콘텐츠 서버나 분석 정보 수집 서버가 없습니다. Amazon 자체의 Kindle 이용 정보 처리는 Amazon 정책이 별도로 적용됩니다.

## 제3자 라이선스

확장에는 Tesseract.js, OCR 코어, 10개 언어 데이터와 나눔고딕·나눔명조가 포함됩니다. 라이선스와 고지는 [THIRD_PARTY_NOTICES.txt](https://github.com/recursivecurry/kindle-ai-translator/blob/main/public/THIRD_PARTY_NOTICES.txt)에 정리했습니다. 설치 ZIP에는 루트의 고지 파일, `licenses/`의 JavaScript 의존성 라이선스, `vendor/` 및 `TESSDATA-LICENSE.txt`의 OCR 라이선스, `fonts/`의 글꼴 라이선스가 포함됩니다. 포함된 구성 요소를 재배포할 때 해당 고지를 유지하세요.

제3자 소프트웨어 라이선스는 책, Amazon 인터페이스·상표 또는 외부 번역 서비스의 이용 권한을 부여하지 않습니다.

## 한계와 문제 해결

- 문자 인식과 번역에는 오류가 있을 수 있습니다. 뜻이 불분명하면 원문과 비교하세요.
- 배치와 글자 크기는 원문을 추정해 맞춥니다. 공간이 부족하거나 원문을 안전하게 덮을 수 없는 문단은 번역하지 않고 남깁니다.
- 표, 수식, 세로쓰기, 사진 위의 글은 제대로 처리하지 못할 수 있습니다.
- OpenAI 번역에 실패하면 API 키와 계정 잔액·사용 한도를 확인한 뒤 **재시도**를 누르세요.
- Chrome 로컬 번역은 설정에서 자동 번역을 켜고 저장해 선택한 언어 모델을 준비하세요. 뷰어에서 아직 준비하지 않은 언어 조합으로 바꾼 경우에도 설정에서 다시 저장해야 합니다. 미지원 기기·언어나 모델 준비 실패 시 오류를 표시하며 OpenAI로 전환하지 않습니다. 로컬 모델은 오역과 내용 누락이 있을 수 있으므로 원문과 비교하세요.
- 확장을 설치하거나 새로고침한 뒤에는 킨들 탭도 새로고침하세요.
