# kindle-ai-translator

[English](README.md)

현재 보이는 Kindle 웹 리더 페이지를 확장에 포함된 Tesseract OCR과 Chrome 내장 로컬 번역기로 번역합니다. 번역은 사용자가 누를 때만 시작하며, 페이지를 자동으로 넘기거나 책 전체를 수집하지 않습니다. 결과는 원문 옆 사이드 패널에 표시합니다.

## 설치와 사용

데스크톱 Chrome 138 이상이 필요합니다. 기기, 브라우저 정책과 언어 조합에 따라 번역 기능을 사용할 수 없을 수 있습니다. 기본 언어는 영어 → 한국어이며 모바일 브라우저는 지원하지 않습니다. API 키와 계정은 필요하지 않습니다.

1. `npm ci`, `npm run build`를 실행하거나 확장 배포 ZIP을 풉니다. GitHub 소스 ZIP은 빌드가 필요합니다.
2. `chrome://extensions`에서 개발자 모드를 켜고 압축해제된 확장 프로그램 로드를 선택해 `dist` 또는 배포 ZIP에서 푼 폴더를 엽니다.
3. `read.amazon.com`, `read.amazon.co.uk`, `read.amazon.co.jp`, `read.amazon.de`에서 책을 엽니다. 확장 아이콘을 눌러 현재 탭 접근을 허용하고 사이드 패널을 엽니다.
4. 원본·번역 언어를 고르고 현재 페이지 번역 버튼을 누릅니다. 최초 실행 시 Chrome이 번역 모델을 다운로드할 수 있으며 진행 상태를 표시합니다.
5. 패널에서 번역문을 읽거나 선택합니다. 취소, 페이지 변경, 화면 크기 변경, 탭 전환, 패널 닫기 시 결과를 지우고 작업을 취소합니다. 다음 페이지는 버튼을 다시 눌러 번역합니다.

모델 다운로드가 실패하면 네트워크 연결 후 다시 시도하세요. 번역 기능이나 언어를 지원하지 않으면 이유를 안내하며 외부 서버로 전환하지 않습니다. 캡처 권한이 없으면 Kindle 탭에서 확장 아이콘을 다시 누르세요. 본문 영역을 찾지 못하는 화면에서는 내부 도서 데이터를 추출하지 않고 중단합니다.

## 개인정보와 권한

`captureVisibleTab`으로 현재 보이는 탭 화면을 캡처한 뒤, 화면에 표시된 Kindle 페이지 영역만 잘라 OCR에 전달합니다. 캡처 직후 잠시 보관되는 전체 화면에는 탭의 다른 영역도 포함될 수 있습니다. Kindle 이미지 URL을 가져오거나 내부 렌더러, 네트워크 응답, 도서 파일에 접근하지 않습니다.

이미지·OCR 원문·번역문은 현재 작업과 표시를 위한 메모리에서만 처리합니다. 본문 캐시, 분석·오류 수집 SDK, 외부 번역 API는 없습니다. OCR 코드·WebAssembly·언어 데이터는 확장에 포함하며 Chrome이 번역 모델 다운로드와 모델 캐시를 관리합니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md)에 있습니다.

`activeTab`·`scripting`은 사용자가 허용한 탭의 캡처와 본문 좌표 확인, `sidePanel`은 결과 표시, `storage`는 업그레이드 시 예전 API 키와 설정 삭제에만 사용합니다. 상시 호스트 권한과 자동 주입 콘텐츠 스크립트는 없습니다. 언어 선택은 패널이 열려 있는 동안만 유지합니다.

## 개발과 검증

```sh
npm ci
npm run check
npm test
npm run package
npx playwright install chromium
npm run test:integration
```

브라우저 통합 테스트는 직접 작성한 예문, 실제 로컬 OCR, 모의 Translator API를 사용합니다. 실제 Chrome 번역 모델의 품질과 확장 아이콘으로 부여하는 캡처 권한은 별도 검증이 필요합니다. 남은 기기·릴리스 검증은 [docs/VALIDATION.md](docs/VALIDATION.md)에 기록합니다. CI는 수동 검토할 Draft 릴리스만 준비합니다.

## 제한과 공개 전 확인

OCR은 문단 순서, 각주, 표, 수식, 이미지 속 글을 잘못 인식하거나 줄 끝 하이픈을 남길 수 있습니다. 긴 문단은 나누어 번역하므로 문맥이 약해질 수 있습니다. 프레임 안의 리더나 변경된 Kindle 화면 구조는 지원하지 못할 수 있습니다. 실제 대상 기기의 번역 품질과 지연시간 검증은 남아 있습니다.

개인 독서 보조를 위한 비공식 프로젝트이며 Amazon 또는 Kindle과 제휴하지 않습니다. 상표는 각 소유자에게 속합니다. 로컬 처리만으로 복제·번역 권한이 생기지 않습니다. 관련 저작권법과 서비스 약관을 확인해야 하며 면책 문구가 허용을 보장하지 않습니다. 법률 검토는 공개 전 필수 확인 사항으로 남아 있습니다.

소스 코드는 [MIT](LICENSE)로 제공합니다. OCR·언어 데이터 라이선스는 `public/THIRD_PARTY_NOTICES.txt`와 배포물의 `vendor`에 포함합니다. Chrome 번역 모델은 재배포하지 않습니다. 이전 스크린샷과 외부 API 코드는 현재 트리와 배포물에서 제거했지만, 공유된 Git 이력은 변경하지 않았습니다.
